# TextClean · 超好用的正则/格式清洗小工具

从 PDF 或网页复制出来的文本，总是带着奇奇怪怪的空格、换行、乱码，手动删到崩溃？
**粘贴进去，点「一键清洗」** —— 多余空行、段落折行、不可见字符、全角/半角、中英文标点，一次搞定。

- 复制 PDF 里一段话，中间全是硬换行？→ 勾「合并 PDF 折行」，句子自动接回去。
- 网页复制来的段落，空行多得离谱？→ 勾「删除多余空行」，一键压缩。
- 从奇怪站点复制，混进看不见的零宽字符，粘到别处排版就乱？→ 自动清掉。
- 中英混排标点看着别扭？→ 一键把英文标点转中文，或中文标点转英文。

## 下载安装

前往 [**Releases**](https://github.com/onlyThat/TextClean/releases) 页面下载最新版：

| 文件 | 说明 |
| --- | --- |
| `TextClean-Setup-<版本>.exe` | 安装包（推荐），双击安装，自动创建开始菜单/桌面快捷方式 |
| `TextClean.exe` | 免安装单文件版，下载后直接双击即可 |

**系统要求**：Windows 10/11（64 位），无需安装 Python。程序不联网、不上传任何内容。

## 快速开始

### 方式一：用安装包 / exe（推荐）

1. 从 Releases 下载并安装（或直接双击 `TextClean.exe`）
2. 把乱糟糟的文本**粘贴到左边**
3. 选个预设（或自己勾选项），点 **一键清洗**
4. 右边就是干净的结果，可「复制结果」「保存为 txt」

### 方式二：Python 源码运行

```bat
python main.py
```

> 仅需标准库；装了 `tkinterdnd2` 可把 txt 文件直接拖进窗口。

## 能做什么

| 清洗动作 | 说明 |
| --- | --- |
| 去掉不可见字符 | 零宽空格、零宽连接符、软连字符、BOM、方向控制符、控制字符 |
| 全角 ↔ 半角 | 全角字母数字转半角、全角空格转普通空格 |
| 合并多余空格 | 多个连续空格 / 制表符合并成一个；可去掉汉字之间的空格 |
| 去行首尾空白 | 每行两端多余的空格、制表符 |
| 删除多余空行 | 连续空行压成一个或直接删光（可配置） |
| 合并 PDF 折行 | 把被硬换行截断的句子接回一段；句末标点、列表项会正确断段 |
| 标点转换 | 英文标点→中文（`，。！？（）""`），或中文标点→英文 |

### 预设

一次点选，自动勾好常用组合：

- **默认（推荐）**：常规清洗，最常用
- **PDF 复制文本**：额外合并折行、去掉汉字间空格
- **网页 / 聊天记录**：保留最多一个空行做段落分隔
- **只去乱码空格**：只处理空格和全角，不动段落
- **转中文标点 / 转英文标点**

## 细节保障

- **汉字之间的空格**默认去掉（PDF 常把中文排成「今 天 天 气」），但**中英文之间的空格保留**（`使用 Python 编写` 不变）。
- **合并折行**时会识别句末标点（`。！？`）和列表 / 小标题（`1.`、`一、`、`（1）`、`•`），遇到就断段，不会把两段糊成一段。
- **英文断词**（`inter-\nnational`）会拼回 `international`，而不是 `inter-national`。
- **标点转换**只看句子内部：小数点 `3.14`、代码、数字不会被误改。
- **零宽字符 / BOM** 这类肉眼看不见的脏字符，粘贴时看不出来但会让排版错乱，这里一并清掉。

## 快捷键

- `Ctrl+Enter`：一键清洗

## 从源码打包 exe

```bat
pip install pyinstaller pillow tkinterdnd2
build.bat
```

产物在 `dist\TextClean.exe`（单文件，约 10–15 MB，目标机无需装 Python）。

## 测试

```bat
python tests\test_core.py
python tests\test_gui_headless.py
```

- `test_core`：44 项断言，覆盖不可见字符、宽度、空格、空行、折行合并、标点转换、文件 IO
- `test_gui_headless`：隐藏窗口构造界面、切预设、喂文本、清洗、替换、清空
